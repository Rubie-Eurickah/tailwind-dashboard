# Tailwind Dashboard

A modern, responsive dashboard built with **Tailwind CSS** as part of my frontend development journey. This project focuses on translating UI designs into clean, reusable, and responsive components while improving my understanding of Tailwind's utility-first workflow.

The dashboard simulates a **claims management system**, featuring pages for managing claims, memberships, and providers.

---

## ✨ Features

* Responsive dashboard layout
* Dashboard overview with summary cards
* Claims list page
* Claim details page
* Membership management page
* Providers management page
* Reusable UI components
* Modern, clean interface
* Mobile-friendly design

---

## 🛠️ Tech Stack

* HTML5
* Tailwind CSS

## 🚀 Getting Started

1. Clone the repository.

   ```bash
   git clone https://github.com/your-username/tailwind-dashboard.git
   ```

2. Open the project folder.

3. Install dependencies (if applicable).

   ```bash
   npm install
   ```

4. Start the Tailwind development server.

   ```bash
   npm run dev
   ```
