# 🖥️ Tailwind Dashboard

A modern, responsive dashboard interface built with **Tailwind CSS** as part of my frontend development journey. This project focuses on translating UI designs into clean, reusable, and responsive components while improving my understanding of Tailwind's utility-first workflow.

The dashboard is designed to simulate a real-world claims management system, with multiple pages for viewing and managing claims, memberships, and providers.

## ✨ Current Features

- 📊 Dashboard overview with summary cards
- 📋 Claims list page
- 📱 Fully responsive layout
- 🎨 Modern interface built with Tailwind CSS
- 📐 Clean spacing, typography, and reusable UI components

## 🚀 Planned Features

- ➕ New Claim form
- 👁️ Claim Details page
- 👥 Membership management
- 🏥 Providers management
- 🔍 Search and filtering
- 📄 Pagination
- 🌙 Dark mode *(optional)*

## 🛠️ Built With

- HTML5
- Tailwind CSS

## 🎯 What I'm Learning

Throughout this project I'm practicing:

- Building responsive layouts with Tailwind CSS
- Creating reusable UI components
- Working with Flexbox and CSS Grid
- Organizing scalable page layouts
- Implementing modern dashboard design patterns
